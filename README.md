# AI-Powered Student Virtual Assistant

A Streamlit chat app that helps college students understand academic topics,
programming concepts and study techniques.

- **Live AI mode** - if `ANTHROPIC_API_KEY` is set, answers come from a real AI model (Anthropic Claude API).
- **Demo mode** - if no key is set, the app still runs, but replies are a few **pre-written samples**.
  Every demo reply is labelled *"DEMO MODE - NOT generated by an AI model"*, and the sidebar shows a warning.

## Features

- Text box + **Send** button
- Assistant replies shown in a chat view, with full **conversation history**
- **Clear conversation** button
- Loading spinner while waiting for the AI, and friendly error messages (bad key, rate limit, no internet, empty or too-long input)
- Three clickable **example questions**
- Educational system prompt (see `SYSTEM_PROMPT` in `assistant.py`)
- API key read from an environment variable on the server only - never in the browser or in the code

## Project files

## Install and run on Windows

Requires **Python 3.10 or newer** (check with `python --version`; download from python.org and tick *"Add Python to PATH"*).

Open **PowerShell** or **Command Prompt** in the project folder:

```powershell
# 1. Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate            # PowerShell and CMD

# 2. Install dependencies
pip install -r requirements.txt

# 3. (Optional but recommended) connect a real AI model
copy .env.example .env
notepad .env                       # replace your_api_key_here with your real key, save

# 4. Run the app
streamlit run app.py
```

The app opens at <http://localhost:8501>. Stop it with `Ctrl + C`.

If PowerShell blocks activation ("running scripts is disabled"), run this once in that window and try again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### Setting the key without a .env file (current window only)

```powershell
$env:ANTHROPIC_API_KEY="paste-your-key-here"      # PowerShell
```
```bat
set ANTHROPIC_API_KEY=paste-your-key-here         :: Command Prompt
```

Then run `streamlit run app.py` in the same window. The sidebar should say **Live AI mode**.
Optionally set `ANTHROPIC_MODEL` in `.env` to choose a different model.

## Run the tests

```powershell
python run_tests.py
```

This sends the three required inputs through the same code the app uses and writes
`results/test_results_<mode>.md` and `.json` (`live` if a key is set, otherwise `demo`).
Run it **once without a key and once with a key**, then copy the live results into `REPORT.md`.

The three inputs: `Explain machine learning in simple terms.`,
`Explain synchronous vs asynchronous JavaScript.`, `Explain it.`

## Troubleshooting

| Problem | Fix |
|---|---|
| Sidebar says DEMO MODE although you added a key | The key is still the placeholder, `.env` is not in the project folder, or you did not restart the app. |
| "The API key was rejected" | Re-copy the key into `.env` with no quotes or spaces. |
| "The configured model was not found" | Set `ANTHROPIC_MODEL` in `.env` to a model your account can use. |
| `streamlit` is not recognised | Activate the virtual environment first (`.venv\Scripts\activate`). |

## Privacy note

Questions are sent to the AI provider in live mode. Do not type passwords, ID numbers
or other personal data. Never share or commit your `.env` file (it is listed in `.gitignore`).
